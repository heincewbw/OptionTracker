How This Works

Anomaly = options priced expensively relative to actual recent volatility.
When IV is much higher than HV it means the market is pricing in large moves that historically haven't materialized — creating an edge for option sellers.

IV % (Implied Volatility) — annualized vol priced into the option right now.
HV % (Historical Volatility) — actual 30-day realized price movement, annualized.
IV/HV Ratio — the key anomaly metric. ≥ 1.3 = options cost ≥30% more than realized vol.
Ann. Premium % — annualized return if you collect this premium. Higher = better for sellers.
